# Architecture Decision Records

A decision gets an ADR when it affects more than one component, adds an external
dependency, or changes an SLO or data classification. Copy
[ADR-0000-template](Decisions/ADR-0000-template.md), number it sequentially
(`ADR-0001-kebab-case-title.md`), and add it to `Decisions/.order`.

| ADR  | Title    | Status | Date |
| ---- | -------- | ------ | ---- |
| 0000 | Template | n/a    | n/a  |
